## 系統實際架構

### 核心組件

系統由以下幾個核心部分組成:

```
前端用戶界面
├─ SimpleChatRoom.tsx        核心對話介面
│  ├─ 左側: NPC 選擇側邊欄
│  └─ 右側: 對話訊息區域
│
後端 API 服務
├─ /api/game/start           建立遊戲 Session
├─ /api/game/chat            處理對話請求
└─ /api/game/session/:id     查詢 Session 狀態
│
對話處理引擎
└─ gameService.ts
   ├─ 載入 NPC Persona
   ├─ RAG 知識檢索
   ├─ 語氣轉換
   ├─ LLM 回答生成
   └─ 關鍵字檢測
```

### 實際運作流程

```
用戶操作流程:
1. 進入對話頁面 → SimpleChatRoom 自動載入
2. 選擇 NPC → 呼叫 /api/game/start 建立 Session
3. 輸入問題 → 呼叫 /api/game/chat 取得回答
4. 切換 NPC → 清空對話,重新建立 Session
5. 持續對話 → Session 保存所有對話歷史
```

### 後端檢測機制

#### 1. 關鍵點檢測 (Key Point Achievement)

```typescript
function checkKeyPointAchieved(
  userMessage: string,
  assistantResponse: string,
  conversationHistory: Array<{ role: string; content: string }>
): { id: string; title: string; description: string } | null {

  const keyPoints = [
    {
      id: 'kp1',
      title: '警察的角色',
      keywords: ['警察', '權力', '控制', '巡查', '維持秩序']
    },
    {
      id: 'kp2',
      title: '保甲制度',
      keywords: ['保甲', '甲長', '十戶', '壯丁團', '連帶責任']
    },
    {
      id: 'kp3',
      title: '連坐處罰',
      keywords: ['連坐', '處罰', '連帶', '責任', '懲罰']
    },
    {
      id: 'kp4',
      title: '土地調查',
      keywords: ['土地調查', '地籍', '田賦', '測量', '土地權']
    },
    {
      id: 'kp5',
      title: '專賣制度',
      keywords: ['專賣', '鴉片', '食鹽', '樟腦', '菸草']
    }
  ];

  const combinedText = userMessage + ' ' + assistantResponse;

  for (const kp of keyPoints) {
    const matchCount = kp.keywords.filter(keyword =>
      combinedText.includes(keyword)
    ).length;

    if (matchCount >= 2) {
      return kp;  // 達成此關鍵點
    }
  }

  return null;
}
```

```typescript
}
```

```typescript
    const regex = new RegExp(`(${keyword})`, 'gi');
    highlighted = highlighted.replace(
      regex,
      '<span class="bg-yellow-200 font-semibold">$1</span>'
    );
  });
  return highlighted;
}
```

```typescript
// 使用 localStorage 保存進度
function saveProgress() {
  localStorage.setItem('game-progress', JSON.stringify({
    sessionId,
    messages,
    currentStageIndex,
    completedStages,
    evalResult,
    timestamp: Date.now()
  }));
}

// 恢復進度
function loadProgress() {
  const saved = localStorage.getItem('game-progress');
  if (saved) {
    const progress = JSON.parse(saved);
    // 檢查是否在 24 小時內
    if (Date.now() - progress.timestamp < 86400000) {
      return progress;
    }
  }
  return null;
}
```
