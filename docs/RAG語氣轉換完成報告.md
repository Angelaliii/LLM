## 🎯 實際運作流程

```
用戶問題: 「警察在地方上怎麼管理?」
    ↓
1. 語意搜尋知識庫
   → 找到相關條目: JP004(警察政治)、JP023(社會風俗)
    ↓
2. 根據 NPC 角色過濾
   → 小清可以理解: JP004、JP023 (有「學生」標籤)
   → 過濾掉: 法律細節、土地調查技術等
    ↓
3. 轉換成角色語氣
   「總督府建立警察制度」
   → 「政府建立了警察制度」(移除組織名)
   → 「他們建了警察制度」(學生視角)
    ↓
4. 加入使用指南
   「⚠️ 以上內容僅供參考,用自己的話回答,不要背誦!」
    ↓
5. 整合到 System Prompt
   + NPC 回答規則
   + 正確/錯誤範例
   + 時代背景限制
    ↓
6. LLM 生成角色化回答
   「警察大人很兇!他們會叫大人們組織壯丁團...」
```
