# 關卡完成提示功能說明

> **更新日期**: 2025-11-30  
> **功能**: 關卡完成恭喜卡片系統

---

## 📌 功能概述

當玩家在對話中提到關卡的所有關鍵字時,系統會自動彈出一張精美的恭喜卡片,告知玩家已完成當前關卡,並提示下一關的內容。

---

## ✨ 主要功能

### 1. 自動關鍵字檢測
- **檢測範圍**: 玩家輸入 + NPC 回覆
- **檢測時機**: 每次對話後
- **檢測邏輯**: 檢查消息中是否包含當前關卡的關鍵字

### 2. 即時視覺反饋
- **線索高亮**: 當玩家發現關鍵字時,左側線索列表會高亮顯示
- **閃爍動畫**: 新發現的線索會有 2 秒的黃色閃爍效果
- **進度顯示**: 實時顯示「已收集 X / 總數 Y」

### 3. 恭喜卡片
當收集到所有關鍵字後,會彈出恭喜卡片,包含:
- ✅ **已完成關卡**: 顯示關卡標題和完成提示
- 🔑 **下一關預告**: 顯示下一關的標題和描述
- 🎯 **兩個選項**:
  - 「留在本關」: 關閉卡片,繼續對話
  - 「前往下一關」: 進入下一關卡

### 4. 特殊處理
- **最後一關**: 顯示「任務完成」,按鈕改為「前往總結」
- **自動跳轉**: 完成最後一關後自動跳轉到 S4 任務總結

```typescript
const handleStageComplete = () => {
  setCompletedStages(prev => [...prev, currentStage.id]);
  missionActions.completeStage(currentStage.id, collectedKeywordsInStage);
  
  if (currentStageIndex < mission.stages.length - 1) {
    setCurrentStageIndex(prev => prev + 1);
    missionActions.nextStage();
    setCollectedKeywordsInStage([]);
    setShowCompletionCard(false);
  } else {
    missionActions.goToStage('S4');
  }
};
```

## 🎯 用戶體驗流程

```
1. 玩家進入關卡
   ↓
2. 查看左側「需要發現的線索」
   ↓
3. 與 NPC 對話,提到關鍵字
   ↓
4. 線索高亮 + 閃爍動畫
   ↓
5. 收集到所有線索
   ↓
6. 1.5 秒後彈出恭喜卡片
   ↓
7. 選擇「留在本關」或「前往下一關」
   ↓
8. 重複 1-7 直到完成所有關卡
   ↓
9. 最後一關完成 → 自動跳轉到任務總結 (S4)
```

## ⚠️ 注意事項

1. **關鍵字大小寫**: 目前採用精確匹配,需要確保關鍵字定義準確
2. **重複檢測**: 已完成的關卡不會再次觸發檢測
3. **NPC 切換**: 切換 NPC 不會重置當前關卡進度
4. **關卡順序**: 必須按順序完成關卡,不能跳關
