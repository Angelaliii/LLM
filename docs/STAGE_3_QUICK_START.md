## 🚀 完整遊戲流程

```
開始遊戲
  ↓
S0: MissionList (任務列表)
  ├─ 選擇任務 "日本統治下的權利與土地：歷史修復任務"
  ↓
S1: S1_FileDecryption (文件解密)
  ├─ 掃描檔案內容
  ├─ Hover 缺漏欄位查看提示
  ├─ 點擊 "開始調查"
  ↓
S2: S2_NpcSelection (NPC 選擇)
  ├─ 選擇 3 個 NPC 之一
  │   ├─ 警察官
  │   ├─ 學生
  │   └─ 土地測量師
  ├─ 點擊 "訪談"
  ↓
S3: S3_GuidedInquiry (後端對話)
  ├─ 與 NPC 進行多輪對話
  ├─ 收集歷史線索
  ├─ 達成條件 (6 輪對話) 後自動進入 S4
  ↓
S4: S4_ArchiveRepair (檔案修復拖曳遊戲) ⭐ NEW
  ├─ 拖曳 5 張線索卡片
  ├─ 放入 3 個空缺欄位
  ├─ 進度 0% → 100%
  ├─ 100% 時解鎖按鈕
  ├─ 點擊 "檔案修復完成 - 進入 S5"
  ↓
S5: S5_Reflection (反思完成) ⭐ NEW
  ├─ 閱讀成功訊息 + 歷史反思
  ├─ 選擇下一步:
  │   ├─ "重新開始" → 回到 S0
  │   └─ "離開遊戲" → 回到 /app
  ↓
結束
```

4. 全部正確: 進度 100% + 紅色印章
5. 點擊 "進入 S5" 按鈕

- 理解日治時期台灣的民主運動
