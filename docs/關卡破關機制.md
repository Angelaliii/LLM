## 系統概覽

### 整體架構

系統採用**雙層結構**:
- **外層**: 任務流程階段 (S0-S5) - 控制整體遊戲流程
- **內層**: 關卡系統 (Stages) - 控制單一任務內的小關卡進度

```
任務流程 (S0-S5, 無S2)
└─ S0: 選擇任務
   └─ S1: 任務介紹
      └─ S3: 對話關卡 ← 內含多個 Stages + NPC切換功能
         └─ S4: 總結
            └─ S5: 測驗
```

### 目前已實作的任務

✅ **E2: 臺南：六法下的權力與土地** (日治初期 1905年)
- 共 **6 個關卡** (Stages)
- **3 個 NPC** 角色
- **6 個學習目標**
- **3 題測驗**

## 關卡系統 (Stages)

### 關卡定義

**位置**: `frontend/app/data/missions/tainan-colonial-rule.ts`

```typescript
export interface Stage {
  id: string;                    // 關卡 ID
  type: 'explore' | 'key_question' | 'summary';
  title: string;                 // 關卡名稱
  description: string;           // 關卡說明
  question: string;              // 核心問題
  keywords: string[];            // 關鍵字列表
  availableNPCs: string[];       // 可對話的 NPC
  hint?: string;                 // 提示
  completionNote: string;        // 完成提示
  requiredKnowledgeIds: string[]; // 所需知識點
}
```

### E2 任務的 6 個關卡

| 關卡 ID | 類型 | 標題 | 關鍵字 | 可用 NPC |
|--------|------|------|--------|---------|
| `stage_1_intro` | explore | 法律與權力的基礎 | 總督專制、六三法 | 全部 3 個 |
| `stage_1_5_philosophy` | key_question | 統治哲學與高壓手段 | 後藤新平、匪徒刑罰令 | police, surveyor |
| `stage_2_power` | key_question | 基層社會控制 | 警察政治、保甲制度 | police, student |
| `stage_3_finance` | key_question | 財政基礎的建立 | 土地調查、專賣制度 | 全部 3 個 |
| `stage_3_5_infrastructure` | explore | 現代化基礎建設 | 縱貫鐵路、臺灣銀行 | surveyor, student |
| `stage_4_summary` | summary | 總結報告 | 總督專制、警察政治、土地調查 | police |

### 破關條件 (理論設計)

#### 1. 關鍵字匹配
玩家對話中需提到關卡的 `keywords`:
```typescript
keywords: ['總督專制', '六三法', '武官', '法律第六十三號']
```

#### 2. 知識點收集
系統應追蹤玩家是否詢問到相關的 `requiredKnowledgeIds`:
```typescript

```

#### 3. NPC 選擇正確性
某些關卡限定特定 NPC:
```typescript

```

### 破關機制現狀

#### ✅ 已實作的部分
1. **任務流程**: S0 → S1 → S3 → S4 → S5 正常運作
2. **對話系統**: NPC 對話、角色切換功能完整
3. **後端邏輯**: RAG、關鍵字檢測、關卡解鎖判定已實作
4. **資料結構**: 所有關卡、NPC、測驗資料完整定義

#### ❌ 缺失的部分
1. **關卡進度 UI**: 玩家看不到自己在第幾關
2. **關卡切換邏輯**: 沒有自動進入下一關
3. **進度評估顯示**: 沒有學習目標達成率
4. **成就系統**: 沒有關鍵點達成通知

### 如何破關 (理想狀態 vs 實際狀態)

#### 理想狀態 (設計意圖)
```
1. 選擇任務 (S0)
   ↓
2. 閱讀任務介紹 (S1)
   ↓
3. 進入對話 (S3)
   ├─ 第 1 關: 詢問關於「六三法」→ 收集 2+ 關鍵字 → 自動解鎖第 2 關
   ├─ 第 2 關: 詢問關於「統治哲學」→ 收集關鍵字 → 解鎖第 3 關
   ├─ ... (共 6 關)
   └─ 完成所有關卡 + 學習目標達標
   ↓
4. 任務總結 (S4)
   ↓
5. 測驗 (S5) → 完成任務
```

#### 實際狀態 (目前實作)
```
1. 選擇任務 (S0)
   ↓
2. 閱讀任務介紹 (S1)
   ↓
3. 進入對話 (S3)
   └─ 自由對話,無關卡限制
      └─ 玩家不知道何時該進入 S4
          └─ ❓ 需要手動判斷或等待足夠輪數
   ↓
4. (需要手動觸發) 任務總結 (S4)
   ↓
5. 測驗 (S5)
```

### 建議實作順序

1. **第一階段** (1-2 天):
   - 在 SimpleChatRoom 顯示當前關卡資訊
   - 處理後端返回的 `stageUnlocked` 事件
   - 實作關卡進度條 UI

2. **第二階段** (1 天):
   - 實作關鍵字檢測與高亮
   - 新增關卡完成通知
   - 實作自動進入下一關

3. **第三階段** (1-2 天):
   - 串接進度評估 API
   - 顯示學習目標達成率
   - 實作評估觸發邏輯 (每 6 輪對話)

4. **第四階段** (1 天):
   - 優化 NPC 切換視覺效果
   - 新增 NPC 切換提示動畫
   - 測試完整流程
