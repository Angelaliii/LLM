## ❌ 問題 1: NPC ID 不一致

### 問題描述
角色檔案命名與 Stage 中使用的 ID 不匹配:

**角色檔案命名**:
- `backend/data/persona/NPC_JP01_Student.md`
- `backend/data/persona/NPC_JP02_Police.md`
- `backend/data/persona/NPC_JP03_LandSurveyor.md`

**Stage 中使用的 ID** (來自 `jp_story_01_early_rule.json`):
- `police_officer`
- `student`
- `land_surveyor`

### 修正方案
建議在後端建立 NPC ID 映射配置檔:

```json
// backend/data/config/npc_mapping.json
{
  "npc_id_mapping": {
    "student": {
      "file_name": "NPC_JP01_Student.md",
      "file_path": "backend/data/persona/NPC_JP01_Student.md",
      "display_name": "小清",
      "role": "學生",
      "icon": "👧",
      "color": "blue"
    },
    "police_officer": {
      "file_name": "NPC_JP02_Police.md",
      "file_path": "backend/data/persona/NPC_JP02_Police.md",
      "display_name": "佐藤 敬一",
      "role": "警察",
      "icon": "👮",
      "color": "red"
    },
    "land_surveyor": {
      "file_name": "NPC_JP03_LandSurveyor.md",
      "file_path": "backend/data/persona/NPC_JP03_LandSurveyor.md",
      "display_name": "山本 勘助",
      "role": "土地測量員",
      "icon": "📐",
      "color": "green"
    }
  }
}
```

### 實作建議
```python
# backend/services/npcManager.py
import json

class NPCManager:
    def __init__(self):
        with open('backend/data/config/npc_mapping.json') as f:
            self.npc_mapping = json.load(f)['npc_id_mapping']
    
    def load_npc_persona(self, npc_id: str) -> str:
        """根據 npc_id 載入對應的 .md 檔案"""
        if npc_id not in self.npc_mapping:
            raise ValueError(f"Unknown NPC ID: {npc_id}")
        
        file_path = self.npc_mapping[npc_id]['file_path']
        with open(file_path, 'r', encoding='utf-8') as f:
            return f.read()
    
    def get_npc_info(self, npc_id: str) -> dict:
        """取得 NPC 基本資訊"""
        return self.npc_mapping.get(npc_id, None)
```

## ❌ 問題 2: Knowledge Base 的 npc_role_tag 不一致

### 問題描述
在 `knowledge_base.json` 中,`npc_role_tag` 欄位使用的角色名稱不統一:

**NPC Persona 檔案中的稱呼**:
- NPC_JP01: 學生小清
- NPC_JP02: 警察佐藤
- NPC_JP03: 土地測量員山本

**Knowledge Base 中的 `npc_role_tag`**:
- 大部分使用: `["警察", "土地測量員", "文化運動者"]`
- 有些條目使用: `["學生", "警察"]`
- 缺少「學生」的條目很多

### 修正方案
統一 Knowledge Base 的 `npc_role_tag` 使用角色類型,不包含名字:

```json
  // ✅ 正確: 只用角色類型
}
```

❌ 不要用: `["警察佐藤", "學生小清"]`

## ❌ 問題 3: unfamiliar_answer 中的角色稱呼不一致

### 問題描述
在 `knowledge_base.json` 的 `unfamiliar_answer` 中:

**有些使用完整名字**:
- "警察": "那些是在我們日本政府接收前的事..."
- "土地測量員": "這是政治歷史,不是我負責的..."

**有些使用不同稱呼**:
- "蔗農": "我只是種田的..."
- "文化運動者": "..."

### 修正方案
統一使用角色類型作為 key:

```json
{
  "unfamiliar_answer": {
    "警察": "...",
    "學生": "...",
    "土地測量員": "..."
  }
}
```

❌ 不要用不在劇本中的角色:
- "蔗農"
- "文化運動者"

這些角色在當前劇本 (`jp_story_01_early_rule`) 中不存在。
